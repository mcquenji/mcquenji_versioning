Checks if the given release can be applied to the current version. Returns true if the patch can be applied, false otherwise.

If the patch cannot be applied, the applyPatch method should not be called and will throw an ManualInstallRequiredException. In this case use getManualInstructions to get manual installation instructions to show to the user instead.
