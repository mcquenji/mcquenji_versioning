ReleasesDatasourceX

ReleasesDatasourceX extension

Extension on Map<ReleaseChannel, Release> to provide convenient access to different release channels.

This extension provides getter methods to access specific releases based on their release channels. It also provides nullable getter methods to access releases that may be null.

Example usage:

Map<ReleaseChannel, Release> releases = {...};
Release stableRelease = releases.stable;
Release? betaRelease = releases.betaOrNull;
